00

계정 먼저 만들기

컴퓨터를 건드리기 전에 계정부터 만듭니다. 뒤 단계에서 전부 로그인이 필요해서, 여기서 막히면 설치를 다 해놓고도 아무것도 못 합니다.

구글 계정 필수
이미 쓰시는 지메일이면 됩니다. 문서 공유와 화면 회의에 씁니다. 회사 일에 쓸 계정을 하나 정해두시고 그 주소를 알려주세요. 나중에 개인 계정과 섞이면 정리가 번거롭습니다.
GitHub 계정 필수
코드가 사는 곳입니다. github.com/signup에서 무료로 만드시고, 사용자 이름(username)을 알려주세요. 저장소가 비공개라 초대를 받아야 열립니다. 초대 메일이 오면 수락까지 해주셔야 합니다.
2단계 인증을 켜두세요. GitHub가 언젠가 강제하는데, 미리 해두면 나중에 급할 때 안 막힙니다.
Claude 계정과 유료 플랜 유료
claude.ai에서 가입합니다. 무료 플랜으로는 Claude Code를 쓸 수 없습니다. Pro 이상이 필요합니다. 개발을 매일 하실 거면 Pro로 시작해 보고, 사용량이 모자라면 그때 Max로 올리는 순서가 낫습니다.
비용이 나가는 유일한 항목입니다. 누가 결제할지 미리 정해두세요. 회사 카드로 묶을 거면 대표님이 팀 플랜으로 초대하는 방법도 있습니다.
Slack 필수
대화와 알림을 여기로 모읍니다. 초대 링크를 받으시면 가입하고, 맥 앱도 설치해 주세요. 브라우저 탭으로만 열어두면 알림을 놓칩니다. slack.com/downloads/mac
Notion 필수
기획과 회의록, 결정 사항이 쌓이는 곳입니다. 초대를 받으신 뒤 맥 앱도 깔아두시면 검색이 훨씬 빠릅니다.
01

맥에 기본 도구 깔기

여기서부터 터미널을 씁니다. 터미널은 스포트라이트(⌘ + 스페이스)에서 "터미널"이라고 치면 나옵니다. 검은 창이 뜨면 아래 명령을 복사해 붙여넣고 엔터를 누르시면 됩니다.

개발자 도구 (Git 포함) 필수
맥에 Git을 깔아주는 애플 공식 도구 모음입니다. 창이 뜨면 설치를 누르세요. 이미 깔려 있다는 메시지가 나와도 정상입니다. 다음으로 넘어가시면 됩니다.
$ xcode-select --install
Homebrew 필수
맥에서 개발 도구를 설치할 때 쓰는 관리자입니다. 앱스토어의 명령줄 버전이라고 보시면 됩니다. 이걸 깔아두면 다음 단계들이 한 줄로 끝납니다. 맥 로그인 비밀번호를 물어봅니다. 입력해도 화면에 아무것도 안 보이는데 정상이니 그냥 치고 엔터를 누르세요.
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
설치가 끝나면 화면 맨 아래에 "Next steps"라며 두 줄짜리 명령이 나옵니다. 그 두 줄을 반드시 복사해서 실행하세요. 이걸 건너뛰면 다음 단계에서 brew: command not found 가 뜹니다. 애플 실리콘 맥에서 가장 흔한 실수입니다.
VS Code 필수
코드를 보고 고치는 편집기입니다. 앞으로 작업의 대부분이 여기서 일어납니다.
$ brew install --cask visual-studio-code google-chrome
크롬도 같이 깔립니다. 만든 화면을 확인할 때 씁니다. 메뉴가 영어라 불편하시면 VS Code를 열고 확장(⌘⇧X)에서 Korean Language Pack을 검색해 설치하세요.
GitHub CLI 필수
터미널에서 GitHub에 로그인하고 PR을 올리는 도구입니다. 이걸 쓰면 SSH 키 같은 복잡한 설정을 안 해도 됩니다.
$ brew install gh
02

GitHub에 로그인하고 저장소 받기

여기까지 오면 코드를 내려받을 수 있습니다. 앞에서 저장소 초대를 수락하셨는지 먼저 확인하세요.

GitHub 로그인 필수
아래를 실행하면 질문이 몇 개 나옵니다. GitHub.com → HTTPS → Yes → Login with a web browser 순서로 고르시면 됩니다. 여덟 자리 코드가 뜨면 복사하고 엔터를 누르세요. 브라우저가 열리면 그 코드를 붙여넣습니다.
$ gh auth login
커밋에 쓸 이름 등록 필수
누가 무엇을 고쳤는지 기록에 남기기 위해서입니다. 따옴표 안을 본인 이름과 GitHub에 등록한 메일 주소로 바꿔서 실행하세요.
$ git config --global user.name "본인 이름"
$ git config --global user.email "본인@메일.com"
저장소 내려받기 필수
홈 폴더 아래에 작업 폴더를 만들고 코드를 받습니다. 마지막 줄까지 실행하면 VS Code가 그 폴더를 열고 뜹니다.
$ mkdir -p ~/work && cd ~/work
$ gh repo clone lian220/onnit
$ cd onnit && code .
권한 오류가 나면 초대를 아직 수락하지 않으신 겁니다. 메일함에서 GitHub 초대를 찾아 수락한 뒤 다시 실행하세요.
03

Claude Code 설치

실제로 코드를 같이 쓰는 도구입니다. Node.js 같은 건 따로 안 깔아도 됩니다. 예전 안내에는 필요하다고 나오는데 지금은 아닙니다.

Claude Code 필수
설치하고 나서 claude 를 치면 로그인 창이 브라우저에 열립니다. Claude 계정으로 로그인하시면 끝입니다.
$ brew install --cask claude-code
$ claude
브라우저가 안 열리면 터미널에서 c 를 눌러 주소를 복사한 뒤 직접 붙여넣으세요.
VS Code 확장 권장
검은 터미널 창이 부담스러우면 이쪽이 훨씬 편합니다. VS Code에서 확장 탭(⌘⇧X)을 열고 Claude Code를 검색해 설치하세요. 파일을 눈으로 보면서 옆에서 대화할 수 있습니다.
처음 며칠은 이 확장만 쓰셔도 됩니다. 터미널은 익숙해진 다음에 넘어가도 늦지 않습니다.
데스크톱 앱 선택
따로 창을 띄워 쓰고 싶으시면 claude.ai/download에서 받으세요. 급할 때는 설치 없이 claude.ai/code를 브라우저로 열어도 됩니다.
04

제대로 됐는지 확인

아래를 한 줄씩 실행하고, 결과가 오른쪽처럼 나오는지 보세요. 하나라도 다르면 그 단계로 돌아가시면 됩니다. 결과를 캡처해서 Slack에 올려주시면 제가 봐드립니다.

확인 명령 다섯 개 필수
$ git --version
$ brew --version
$ gh auth status
$ claude --version
$ ls ~/work/onnit
명령이렇게 나오면 정상
git --versiongit version 2.x.x
brew --versionHomebrew 4.x.x
gh auth status✓ Logged in to github.com account …
claude --version숫자로 된 버전
ls ~/work/onnitindex.html, README.md 등 파일 목록
command not found 가 뜬다면 그 도구가 안 깔렸거나 Homebrew의 "Next steps" 두 줄을 건너뛴 겁니다. 터미널을 완전히 껐다가 다시 열고 한 번 더 해보세요. 그래도 안 되면 01단계로 돌아갑니다.
첫 PR 연습 필수
설치가 됐다고 끝이 아니라, 한 바퀴 돌려봐야 진짜 끝입니다. README 파일에 본인 이름 한 줄을 추가하는 것을 첫 작업으로 하세요. Claude Code를 열고 이렇게 부탁하시면 됩니다.
README.md 맨 아래에 "## 팀" 항목을 만들고
내 이름을 한 줄 추가해줘. 새 브랜치를 파서 커밋하고 PR까지 올려줘.
이 한 바퀴가 돌면 브랜치, 커밋, PR이 전부 동작한다는 뜻입니다. main 브랜치에 직접 올리지 않는 것이 유일한 규칙입니다. 항상 새 브랜치에서 작업하고 PR로 보냅니다.

위 목록에는 없지만 누군가는 해줘야 하는 것들입니다. 이게 안 되어 있으면 그분은 00단계에서 멈춥니다.

  1. GitHub 사용자 이름을 받아 저장소에 초대하기 — gh api -X PUT repos/lian220/onnit/collaborators/사용자이름

  3. Notion 워크스페이스에 초대하기
  4. Claude 요금을 누가 낼지 정하기. 회사에서 낼 거면 팀 플랜으로 묶는 편이 정산이 깔끔합니다
  5. 저장소에 CLAUDE.md 를 두어 코딩 규칙을 적어두기. 그래야 그분의 Claude가 같은 규칙으로 코드를 씁니다
  6. main 브랜치 보호 설정을 켜서 직접 푸시를 막기
